# SS-BMW — сайт

Готовая адаптивная одностраничная версия сайта по утвержденному макету.

## Быстрый запуск

### Способ 1 — без установки программ
Откройте файл `index.html` двойным щелчком. Основная страница откроется в браузере.

### Способ 2 — локальный сервер (рекомендуется)
Если установлен Python:

```bash
cd SS-BMW-site
python -m http.server 8000
```

Затем откройте: http://localhost:8000

### Способ 3 — VS Code
Установите расширение Live Server, откройте папку проекта и нажмите `Go Live`.

## Публикация
Папку можно загрузить на любой статический хостинг: Timeweb, Beget, GitHub Pages, Netlify или Vercel.

## Что уже работает
- адаптивная верстка;
- меню и плавная прокрутка;
- кнопки звонка и Telegram;
- карта Яндекса;
- демонстрационная форма записи;
- оригинальный логотип SS-BMW;
- фотографии локализованы (assets/, вырезаны из макетов, без внешних ссылок).

## Важно
Форма сейчас демонстрационная. Для реальной отправки заявок нужно подключить Telegram-бота, CRM, e-mail или серверный обработчик.
